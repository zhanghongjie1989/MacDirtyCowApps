## ⚠️ **重要安全提醒**

### 🔴 高风险工具使用警告
- **Filza系列**: 可直接修改系统文件，操作不当可能导致系统崩溃
- **DirtyCow系列**: 利用系统漏洞，存在安全风险
- **TrollStore**: 永久性修改系统，难以完全恢复

### 🟡 使用建议
- **备份数据**: 使用任何工具前务必备份重要数据
- **版本匹配**: 确保工具版本与iOS版本兼容
- **来源可靠**: 只使用可信任来源的工具
- **逐步测试**: 先在非重要设备上测试

### 🟢 基本安全措施
- 定期检查设备状态
- 监控系统性能变化
- 及时更新安全补丁
- 避免安装未知应用
